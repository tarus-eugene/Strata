# 101 Downloader 0.2.0

Strata is now **101 Downloader**, with an orange, black, white and gray palette, a new 101 download-arrow logo, and matching desktop, tray, browser companion and installer branding. Existing download history, settings and extension identity are retained. The GitHub repository remains tarus-eugene/Strata.

- HTTP workers pull chunks from a shared per-download queue, reuse pooled connections, and split slow remaining ranges when other workers become idle. Splits stop and flush the original writer before redistributing bytes. Resume and final assembly support the resulting range order.
- Browser capture suppresses Chromium's download UI where supported, waits for filename determination, and restores browser handling on failed handoff. The app recovers names from server headers, redirects and MIME information, including late headers before publication.
- **Delete from device** permanently removes owned output and partial files after transfer writes stop. Failed deletions retain an entry for retry. Cancel retains partial files.
- New download opens in a centered modal. The table includes ETA, the empty detail prompt is centered, and summary cards are removed. All native inputs use a blinking caret at the Windows rate.

Install **101-Downloader-Setup-0.2.0-x64.exe** after quitting the running app through its tray menu. Installed executables are named `101Downloader.exe`, `101Downloader-cli.exe` and `101Downloader-Bridge.exe`. Upgrades keep the previous install directory and existing Strata history when present. Uninstall preserves downloads and history.

Reload the browser companion after upgrading and approve the new **downloads.ui** permission if your browser requests it. Its native host identity and extension ID remain unchanged. Compatible Chromium browsers share the same extension; browser policies and unsupported APIs can limit capture or UI suppression. Browser-only transfers may restore the profile-wide browser download UI.

All 42 Rust checks and 17 extension checks pass; Clippy passes with warnings denied. Checks cover keep-alive connection reuse and limits, slow-tail splitting with pause/resume and exact bytes, filename recovery, permanent deletion, protocol transfers, input timing, native messaging, and extension lifecycle behavior. Installer assets carry SHA-256 checksums. The installer is unsigned. The current popup visuals and a full install/upgrade/uninstall cycle still need an interactive Windows check.
