Strata's first Windows release: a native Rust and GPUI download manager with parallel HTTP, FTP, SFTP, WebDAV, native torrents, verified Metalinks, video extraction, and a Chromium browser companion.

### Downloads

- **Strata-Setup-0.1.0-x64.exe** — Windows installer with the app, native browser bridge, runtime files, and shortcuts. No administrator access required.
- **Strata-Setup-0.1.0-x64.exe.sha256** — SHA-256 checksum for the installer.
- **strata-browser-extension.zip** — browser companion for a separate unpacked installation. The installer also includes it.

### Included

- Concurrent HTTP range downloads with 1, 4, 8, or 16 connections, safe assembly, retries, and fallback for servers without range support.
- Pause/resume, saved history, per-connection progress, search, and download folder settings.
- A dark native interface, custom title bar, Strata logo, and text alignment at fractional DPI settings.
- Closing hides Strata to the system tray while downloads continue. Click its icon to restore; right-click and choose **Quit Strata** to exit.
- A Manifest V3 companion for compatible Windows Chromium browsers. Browser downloads are canceled only after Strata accepts the handoff; rejected handoffs resume in the browser.
- FTP anonymous/password authentication and REST resume; SFTP password/key authentication, known-host verification, and resume; WebDAV Basic auth.
- HTTP / HTTPS / SOCKS5 proxy support, with protected credentials in saved history.
- Native v1 / hybrid BitTorrent and magnet transfers through the default `torrent-native` feature. Partial pieces are rechecked and seeding stops when the job completes.
- Metalink v3/v4 with ordered mirror failover and SHA-256, SHA-512, and MD5 verification before publication.
- Video sites through bundled yt-dlp, FFmpeg, and Deno, plus `strata-cli.exe` with `--ftp`, `--sftp`, `--webdav`, `--metalink`, and `--ytdlp` overrides.

### Install and connect

Run the setup EXE and leave **Connect the browser companion** selected. In Strata Settings, use **Extension folder** to find the bundled extension. Open your browser's extensions page, enable **Developer mode**, choose **Load unpacked**, and select that folder. Repeat in each browser profile.

Quit Strata from its tray menu before upgrading or uninstalling. Uninstall retains downloaded files, partial transfers, history, and settings.

### Requirements and limitations

- Windows 10 version 2004 or later, or Windows 11, with a working GPU driver. Windows x64 binaries are included.
- The installer is unsigned; Windows may show a reputation warning.
- Login-only, cookie-dependent, browser-generated, and POST-generated downloads may need to stay in the browser. Browser cookies and passwords are not exported automatically.
- SFTP requires a verified entry in your OpenSSH known_hosts file; unknown, changed, and revoked keys are refused. Saved source/proxy credentials are protected for your Windows account.
- Video sites may impose login, DRM, regional, or availability restrictions. Automatic video routing covers YouTube, Vimeo, Twitch, TikTok, and Instagram; use `--ytdlp` for other supported sites.
- Browser policies can disable unpacked extensions or native messaging. Chromium and Brave were tested end to end; every Chromium fork has not been tested individually.
- Text alignment reduces avoidable softness; GPUI still uses its grayscale text rasterizer.

### Verification

28 Rust tests (including the optional yt-dlp transfer test), 9 extension tests, and Clippy passed. Loopback fixtures verified FTP/SFTP resume, WebDAV, proxies, Metalink checksum recovery, and native torrent/magnet transfers. The release CLI also completed real HTTPS and local Metalink downloads with verified bytes. The installer passed install, repeat-install upgrade, bundled CLI/media-helper startup with a restricted PATH, running-app protection, registration ownership, and uninstall checks. Real Chromium and Brave downloads were handed to the app and verified byte for byte; capture-off downloads remained in the browser.
