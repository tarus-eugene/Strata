Strata v0.1.1 makes the download queue denser and moves transfer details below it.

### Changes

- Replaced download cards with a table showing file name, size, status, progress, speed, and pause/resume actions.
- Moved the right-hand inspector to a bottom panel, with transfer summary, connection progress, source, destination, and file actions.
- Replaced the introductory inspector headings and explanations with “Click on a download to view more info.” when nothing is selected.
- Removed rounded corners throughout the desktop app and browser companion.
- Kept the queue and details independently scrollable and reduced summary spacing to leave more room for downloads.

### Downloads

- **Strata-Setup-0.1.1-x64.exe**: per-user Windows installer, including the app, CLI, browser companion, and media helpers.
- **Strata-Setup-0.1.1-x64.exe.sha256**: installer checksum.
- **strata-browser-extension.zip**: browser companion for manual unpacked installation.

Quit Strata from the system tray before upgrading. History, settings, and downloaded files are retained. Reload the browser extension after updating its files.

### Verification and limitations

The native layout passed compilation and Clippy. All 9 browser-companion tests passed. Both staged executables reported version 0.1.1, and an isolated app/CLI smoke test completed real HTTPS and local Metalink transfers with matching bytes.

The installer remains unsigned. Visual inspection of the native layout was unavailable in this environment. The full install/upgrade/uninstall cycle was not rerun while another copy of Strata was running.
