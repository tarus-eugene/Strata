# 101 Downloader 0.2.1

The desktop app, system tray, browser companion and Windows installer now use the supplied orange hanging orangutan logo. The original PNG, including its colors and black background, is preserved in assets/brand/mark.png. Matching icons are exported at 16, 32, 48, 128 and 256 pixels; the old 101 arrow artwork is removed.

Quit the app through its tray menu before installing **101-Downloader-Setup-0.2.1-x64.exe**. Reload the browser companion to refresh its icon. Existing history, settings, download files and extension identity are retained.

This is a branding update; the v0.2.0 download engine and interface behavior are retained. The installer is unsigned. A live visual check and a full install/upgrade/uninstall cycle were not available in this environment.
