# 101 Downloader 0.3.0

- Check stable GitHub updates automatically at startup or manually in Settings; download installers through the queue.
- Rename downloads with the filename selected except its extension. Completed files and folders move without replacing existing paths.
- Select rows with checkboxes, Ctrl/Shift clicks, or select-all, and apply batch actions. High, Normal, and Low priorities control queue order.
- Set a speed limit for each selected download or a shared global cap in Settings. Active transfers pause briefly to apply changes, then resume.
- A compact toolbar centers search, puts selection actions on the left, and groups Filter, Settings, and New download on the right. With no selection, the left side shows only Pause all.
- Visible draggable scrollbars and smooth mouse-wheel scrolling cover the queue, Settings, and overflowing dialogs. Settings has an orange border while open.
- Created and Completed at follow Windows date and 12/24-hour settings. The headerless bottom panel fits without scrolling and collapses from the permanent bottom footer.
- Accepted downloads restore and foreground the app. Its window title is simply 101 Downloader.
- Fix title-bar dragging by keeping keyboard focus handling below the native caption area.

Quit through the tray menu before installing **101-Downloader-Setup-0.3.0-x64.exe**. Existing history, settings, downloads, and browser identity are retained. Reload the browser companion after upgrading.

Limits use KiB/s; 0 is unlimited. Nonzero global and torrent limits start at 16 KiB/s. Under a global cap, FTP, video, torrent, and Metalink jobs run one at a time to preserve the shared cap. Older completed entries without a saved completion timestamp show a dash.
