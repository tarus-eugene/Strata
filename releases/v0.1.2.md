Strata v0.1.2 simplifies navigation and makes the transfer panel adjustable.

- Removed the left sidebar, workspace label, and breadcrumbs. Filter is at the top left; Settings is at the top right.
- Added a draggable bottom-panel divider with keyboard Up/Down resizing and a saved height.
- Replaced separate connection lanes with one byte-weighted segmented download bar.
- Added a three-dot menu to every download row with contextual pause/resume, open, open folder, copy download link, cancel, and delete actions. Delete stops the transfer and removes its history entry while preserving files and partial data.
- Automatic browser downloads now open or restore Strata after acceptance. No Download with Strata command is needed. Downloads awaiting browser scanning are retried once reported safe; concurrent events cannot queue duplicate transfers.

Install **Strata-Setup-0.1.2-x64.exe** after quitting Strata from its tray menu. The release also includes its SHA-256 checksum and **strata-browser-extension.zip**. Reload the companion in each browser after updating its files; automatic capture is enabled by default.

Verification: 31 Rust tests and 12 browser-companion tests passed, including history compatibility, resizing limits, unequal segment geometry, deletion, automatic window-opening requests, and duplicate-event prevention. Clippy is clean. A real native-host smoke test launched the isolated release app from a framed browser request and verified its downloaded HTTPS bytes.

Private, browser-generated, and browser-flagged downloads remain in the browser. Cookie-dependent or POST-generated transfers can require the browser. The installer is unsigned. Native visual inspection was unavailable; the full install cycle was not rerun over the existing user installation.
